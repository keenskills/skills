# Keen Skills site, phase 4 (showcases and motion) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the phase 3 skeleton into the showcase site: a light/dark theme toggle on a new neutral palette taken from jakubantalik.com, real-output showcases for both skills (page-as-data "a screenshot vs the data" with a replayed `check`; the diagram skill's "lint, render, look, fix" loop with a before/after slider and downloads), a copy-prompt flow and package-manager switcher, two animated SVG illustrations of what each skill does, and the motion table from the spec — plus the phase 3 deferred fixes.

**Architecture:** Real output is produced once, locally, by `apps/site/scripts/build-showcases.mjs` (runs the page-as-data CLI against its own `test/fixture.html` and the diagram skill's Northwind example through lint and draw.io) and committed under `apps/site/content/showcase/` and `apps/site/public/showcase/`; `tests/showcases.test.mjs` regenerates what CI can (page-as-data text with Chrome, diagram XML and lint with Python) and fails on drift. Motion is plain CSS: transitions.dev snippets pasted verbatim into `app/motion.css`, illustration keyframes in `app/scenes.css`, and small client components that only flip classes and data attributes. Testable logic lives in plain `.mjs` files under `lib/` (with `.d.mts` types) so `node:test` covers it without a browser; behaviour in the built site is tested with page-as-data itself (`tests/interactions.test.mjs` drives `readPage` with `--click` steps).

**Tech Stack:** Next.js 16.3 (static export), React 19.3, TypeScript 5.9, Tailwind CSS 4.3, Inter + Geist Mono via `next/font/google`, `@keenskills/page-as-data` (workspace) for tests and showcases, Python 3.9+ and draw.io desktop (local showcase generation only), `node:test`.

**Spec:** `docs/superpowers/specs/2026-09-29-skills-monorepo-and-site-design.md` (phase 4 of 5, "Showcases and motion"; sections "Showcases (real output only)", "Copy prompt", "Visual direction", "Motion", "Quality gates"). Handoff: `docs/superpowers/progress.md` ("Phase 4 scope" and "Deferred minors").

## Global Constraints

- Pure static export (`output: 'export'`); no server code. No new runtime dependency: no motion library, no GSAP, no icon package. Every animation is CSS (transitions.dev snippets, `@keyframes`, the View Transitions API for the theme switch).
- Showcases show real output only. Every string presented as tool output comes from a committed file written by `scripts/build-showcases.mjs`; illustrations are labelled as illustrations and any tool text in them is taken from those files.
- Example content uses fictional names only (Northwind Traders, Contoso). Never a real client name.
- Palette and aesthetic follow jakubantalik.com: near-monochrome. Light `#fdfdfd` page, `#ffffff` cards, `#333` text, `#666` secondary; dark `#0f0f0f` page, `#181818` cards, `#e4e4e7` text, `#a1a1aa` secondary; 16 px card radius; cards drawn with an inset 1 px ring plus a 1 px bottom inset and a faint drop (`0 1px 3px` at 4%); hover is a 2% black (light) or 2% white (dark) overlay; Inter for text. Tokens stay OKLCH on `:root`, dark under `@media (prefers-color-scheme: dark) { :root:not([data-theme="light"]) }` and again under `:root[data-theme="dark"]`.
- All text meets 4.5:1 in both themes (checked by `tests/tokens.test.mjs`); status colours (`--danger`, `--warn`, `--ok`) too.
- Motion rules (spec "Motion", Emil Kowalski): decide by frequency first; enter with ease-out, move on screen with ease-in-out, never ease-in; UI transitions 300 ms or less (explanatory illustrations may run longer); animate only `transform`, `opacity`, `filter`, `clip-path` and SVG `stroke-dashoffset` — the two spec-sanctioned exceptions are Card resize (`width`) on the 390/1440 frame and the FAQ `block-size` tween; never `transition: all`; nothing starts from `scale(0)` (lowest `0.95`); exit faster than enter; hover effects only on `(hover: hover) and (pointer: fine)` (Tailwind v4 `hover:` already is); no animation on keyboard-initiated actions (arrow keys in tabs move the pill instantly); every snippet keeps its `prefers-reduced-motion` block; reduced motion keeps opacity/colour and drops movement; scroll-triggered animations run once.
- transitions.dev snippets are pasted verbatim from `~/.claude/skills/transitions-dev/<nn>-*.md` (their CSS block and reduced-motion guard). Site-specific additions go in separate rules below the snippet, never as edits inside it.
- Every page passes `page-as-data check` at 390 and 1440 px with 0 errors and 0 warnings (`pnpm site:check`). This is the phase exit gate, with the reduced-motion pass, the 0.25× review and the Lighthouse budget (LCP under 1.5 s on a mid-tier phone profile, no CLS).
- Copy about a skill comes from its package through `scripts/build-content.mjs`.
- ES modules, no semicolons, single quotes, 2-space indent, LF; comments say why. Commit messages are plain sentences ending with the `Co-Authored-By` line.
- Outward steps (push, Vercel, tags) only after the user confirms.

## Review Focus

1. **A returning visitor's theme.** Someone who chose dark on a light-mode system reloads: the page must paint dark from the first frame (no light flash), code blocks included; with no stored choice the system decides; a blocked `localStorage` must not break the page. Pinned in Task 3 (`tests/lib.test.mjs` runs the head script against fakes; interaction test clicks the toggle).
2. **Copy on a page where the Clipboard API is missing or refused** (plain http, Safari without a user gesture, permissions denied). The button must not say "Copied" when nothing was copied; it falls back to `execCommand('copy')` and otherwise says "Copy failed". Pinned in Task 7 (`copyText` tests with fakes).
3. **Reduced motion and no JavaScript.** Illustrations, the hero reveal, the terminal replay and the success check must all show their final state; nothing may stay invisible waiting for an animation or a script. Pinned in Task 2 (`tests/motion.test.mjs` static rules), Task 9 (`replaySchedule` with `reduced`), Task 11 (scenes are armed only by script, so unarmed = final frame) and Task 12 (`<noscript>` hero rule; pages test).
4. **Showcase output that drifts or leaks the build machine.** Real CLI output contains a random port, absolute paths, timings and failed requests that finish in any order. Committed output must show `http://localhost:3000`, no local path, and the drift check must ignore timings and order but catch any real change. Pinned in Task 4 (`normalizeOutput` / `comparable` tests, `tests/showcases.test.mjs`) and Task 5.
5. **Wide content at 390 px.** A 1440 px screenshot, 200-character output lines, the before/after slider, tooltips near the right edge and the mobile menu must never make the page scroll sideways or hide controls. Pinned by the self-check on every page (Tasks 8–12 each run `pnpm site:check`) and the 390 px interaction tests in Tasks 9, 10 and 12.

`tests/motion.test.mjs`:

```js
// The spec's motion rules, checked on every stylesheet the site ships, so a
// later edit cannot quietly add `transition: all`, a scale(0) entrance or an
// animation without a reduced-motion path.
import assert from 'node:assert/strict'
import { readdirSync, readFileSync } from 'node:fs'
import { describe, it } from 'node:test'

const app = new URL('../app/', import.meta.url)
const sheets = readdirSync(app).filter((f) => f.endsWith('.css')).map((f) => [f, readFileSync(new URL(f, app), 'utf8')])
const motion = readFileSync(new URL('motion.css', app), 'utf8')

/** The text of every @media (prefers-reduced-motion: reduce) block. */
export function reducedBlocks(css) {
  const out = []
  let i = 0
  while ((i = css.indexOf('prefers-reduced-motion: reduce', i)) !== -1) {
    let depth = 0
    let j = css.indexOf('{', i)
    const start = j
    for (; j < css.length; j++) {
      if (css[j] === '{') depth++
      else if (css[j] === '}' && --depth === 0) break
    }
    out.push(css.slice(start, j + 1))
    i = j
  }
  return out.join('\n')
}

describe('motion rules', () => {
  for (const [name, css] of sheets) {
    it(`${name}: never transitions all properties`, () => assert.doesNotMatch(css, /transition(-property)?\s*:\s*all\b/))
    it(`${name}: nothing enters from scale(0)`, () => assert.doesNotMatch(css, /scale\(0(\.0*)?\)/))
    it(`${name}: no ease-in on UI`, () => assert.doesNotMatch(css, /\bease-in\b(?!-out)/))
    it(`${name}: every animation has a reduced-motion path`, () => {
      if (/@keyframes|transition\s*:/.test(css)) assert.match(css, /prefers-reduced-motion: reduce/)
    })
  }

  it('keeps the reduced-motion guard of every pasted transitions.dev snippet', () => {
    const guards = reducedBlocks(motion)
    for (const sel of ['.t-resize', '.t-digit', '.t-text-swap', '.t-dropdown', '.t-icon-swap .t-icon', '.t-success-check', '.t-shimmer::before', '.t-tabs-pill', '.t-tt', '.t-stagger-line']) {
      assert.ok(guards.includes(sel), `no reduced-motion rule for ${sel}`)
    }
  })

  it('defines the spec easings', () => {
    assert.match(motion, /--ease-out:\s*cubic-bezier\(0\.23, 1, 0\.32, 1\)/)
    assert.match(motion, /--ease-in-out:\s*cubic-bezier\(0\.77, 0, 0\.175, 1\)/)
  })
})
```

```tsx
type Theme = 'light' | 'dark'
const current = (): Theme =>
  (document.documentElement.dataset.theme as Theme | undefined) ?? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light')

export function ThemeToggle() {
  const [theme, setTheme] = useState<Theme | null>(null)
  useEffect(() => setTheme(current()), [])
  const label = theme === 'dark' ? 'Switch to light theme' : 'Switch to dark theme'

  function toggle() {
    const next = nextTheme(current())
    const apply = () => {
      document.documentElement.dataset.theme = next
      setTheme(next)

    else apply()
```

```js
import { join } from 'node:path'
import { fileURLToPath } from 'node:url'

const NPX = 'npx @keenskills/page-as-data'

/** Output as a reader should see it: a fixed origin, LF, no trailing blank lines. Timings stay real. */
export function normalizeOutput(text, origin) {
  return text.replaceAll(origin, SHOWN_ORIGIN).replace(/\r\n/g, '\n').replace(/(file:\/\/)?\/(Users|home)\/[^\s:]+/g, '<local path>').trimEnd()

export const pngSize = (buf) => ({ width: buf.readUInt32BE(16), height: buf.readUInt32BE(20) })

/** Runs a command without blocking the event loop (the fixture server lives in this process). */
export function run(cmd, args, opts = {}) {
  return new Promise((done, fail) => {
    const child = spawn(cmd, args, { ...opts, stdio: ['ignore', 'pipe', 'pipe'] })
    let out = ''
    let err = ''
    child.stdout.on('data', (d) => (out += d))
    child.stderr.on('data', (d) => (err += d))
    child.on('error', fail)
    child.on('exit', (code) => done({ code, out, err }))
  })
}

/** Serves the fixture at / and 404s everything else, like a dev server with missing assets. */
async function serveFixture() {
  const html = readFileSync(join(PAD, 'test/fixture.html'))
  const server = createServer((req, res) => {
    if (req.url === '/' || req.url === '/index.html') {
      res.writeHead(200, { 'content-type': 'text/html; charset=utf-8' })
      return res.end(html)
    }
    res.writeHead(404, { 'content-type': 'text/plain' })
    res.end('Not found')
  })
  await new Promise((done) => server.listen(0, '127.0.0.1', done))
  return { origin: `http://127.0.0.1:${server.address().port}`, close: () => server.close() }
}

    const read = {}
    for (const width of [390, 1440]) {
      const file = join(publicDir, `fixture-${width}.png`)
```

```python
"""Makes the "first draft" for the site's lint -> fix showcase from the finished Northwind example.

It undoes three things the lint pass exists to catch - an oversized icon, an icon off its row's
baseline, and two labels on top of each other - and keeps each change only when the real linter
reports it, so the draft's findings are genuine archdiagram.py output.

Usage: python3 northwind_draft.py <final.drawio> <draft.drawio>   (prints the fixes as JSON)
Needs ARCHDIAGRAM_DIR = the skill's scripts folder.
"""
import copy
import json
import os
import sys
import tempfile
import xml.etree.ElementTree as ET

sys.path.insert(0, os.environ["ARCHDIAGRAM_DIR"])
from archdiagram import lint_file  # noqa: E402


def icons(tree):
    for c in tree.getroot().iter("mxCell"):
        if c.get("vertex") == "1" and (c.get("style") or "").startswith("image;"):
            yield c, c.find("mxGeometry")


def by_id(tree, cid):
    return next((c, g) for c, g in icons(tree) if c.get("id") == cid)


def lint(tree):
    fd, path = tempfile.mkstemp(suffix=".drawio")
    os.close(fd)
    try:
        tree.write(path, encoding="utf-8")
        return lint_file(path)
    finally:
        os.unlink(path)


def num(g, k):
    return float(g.get(k))


def fmt(v):
    return str(int(v)) if float(v).is_integer() else str(v)


def first_that_lints(tree, changes, expect):
    """Applies the first change that adds a lint finding containing `expect`."""
    before = set(lint(tree))
    for change in changes:
        trial = copy.deepcopy(tree)
        cid, fix = change(trial)
        if any(expect in f for f in set(lint(trial)) - before):
            return trial, cid, fix
    sys.exit(f"no candidate produced a lint finding containing '{expect}'")


def grow(cid):
    def change(t):
        _, g = by_id(t, cid)
        w, h = num(g, "width"), num(g, "height")
        g.set("width", "44")
        g.set("height", "44")
        return cid, f"{cid}: icon back to {fmt(w)}×{fmt(h)} px (the draft had it at 44×44)"
    return change


def drop(cid):
    def change(t):
        _, g = by_id(t, cid)
        g.set("y", fmt(num(g, "y") + 7))
        return cid, f"{cid}: moved 7 px up, back onto its row's baseline"
    return change


def crowd(cid, other):
    def change(t):
        (_, g), (_, go) = by_id(t, cid), by_id(t, other)
        x = num(g, "x")
        g.set("x", fmt(num(go, "x") + 12))
        return cid, f"{cid}: moved back to x={fmt(x)}, so its label no longer sits on {other}'s"
    return change


def main(src, out):
    tree = ET.parse(src)
    ids = [c.get("id") for c, _ in icons(tree)]
    fixes, used = [], set()
    tree, cid, fix = first_that_lints(tree, [grow(i) for i in ids], "keep icons 20-28 px")
    fixes.append(fix); used.add(cid)
    tree, cid, fix = first_that_lints(tree, [drop(i) for i in ids if i not in used], "off a common baseline")
    fixes.append(fix); used.add(cid)
    pairs = [(i, j) for i in ids for j in ids if i != j and i not in used and j not in used]
    tree, cid, fix = first_that_lints(tree, [crowd(i, j) for i, j in pairs], "overlap")
    fixes.append(fix)
    ET.indent(tree.getroot(), space="  ")
    tree.write(out, encoding="utf-8")
    print(json.dumps(fixes))


if __name__ == "__main__":
    main(sys.argv[1], sys.argv[2])
```

const stripMd = (s) => s.replace(/`([^`]*)`/g, '$1').replace(/\*\*?([^*]+)\*\*?/g, '$1').replace(/\[([^\]]+)\]\([^)]*\)/g, '$1')

/** The one-paste prompt: install, what it is for, the key commands — all from the skill's own file. */
export function buildPrompt({ title, pkg, install, skillMd }) {
  const body = skillMd.replace(/\r\n/g, '\n').replace(/^---\n[\s\S]*?\n---\n/, '')
  const paras = body.split(/\n{2,}/).map((p) => p.trim())
  const purpose = stripMd(paras.find((p) => p && !p.startsWith('#') && !p.startsWith('```')) ?? '')
  const blocks = [...body.matchAll(/```(?:sh|bash|shell)?\n([\s\S]*?)```/g)].slice(0, 2).map((m) => m[1].trimEnd())
  return [
    `Install the ${title} agent skill in this project: ${install}`,
    `(In Claude Code you can instead run /plugin marketplace add keenskills/skills, then /plugin install ${pkg}@keenskills.)`,
    '',
    `What it is for: ${purpose}`,
    '',
    'Key commands:',
    ...blocks.map((b) => b.split('\n').map((l) => `  ${l}`).join('\n')),
    '',
    'Then read the installed skill file and use it for the work in this project.',
  ].join('\n')
}

/** The README's example prompts, grouped by the ### situation they sit under. */
export function promptGallery(md) {
  const groups = []
  for (const part of md.replace(/\r\n/g, '\n').split(/^### /m).slice(1)) {
    const [title, ...rest] = part.split('\n')
    const text = rest.join('\n')
    const prompts = [...text.matchAll(/^- `([\s\S]*?)`/gm)].map((m) => m[1].replace(/\s*\n\s*/g, ' ').trim())
    if (!prompts.length) continue
    const note = stripMd(text.split('\n- ')[0].trim().split('\n\n')[0]).replace(/\s*\n\s*/g, ' ')
    groups.push({ title: title.trim(), note, prompts })
  }
  return groups
}

/** Last week's npm downloads, or null: a slow or offline registry must not fail the build. */
export async function weeklyDownloads(name, fetchImpl = fetch) {
  try {
    const res = await fetchImpl(`https://api.npmjs.org/downloads/point/last-week/${name}`, { signal: AbortSignal.timeout(3000) })
    if (!res.ok) return null
    const { downloads } = await res.json()
    return Number.isFinite(downloads) ? downloads : null
  } catch {
    return null
  }
}

```js
// Copy that tells the truth: the button says "Copied" only when the text got there.
// Clipboard API first; execCommand for pages or browsers that refuse it.
export async function copyText(text, { clipboard = globalThis.navigator?.clipboard, doc = globalThis.document } = {}) {
  try {
    if (clipboard?.writeText) {
      await clipboard.writeText(text)
      return true
    }
  } catch {}
  try {
    const ta = doc.createElement('textarea')
    ta.value = text
    ta.setAttribute('readonly', '')
    ta.style.position = 'fixed'
    ta.style.opacity = '0'
    doc.body.appendChild(ta)
    ta.select()
    const ok = doc.execCommand('copy')
    ta.remove()
    return Boolean(ok)
  } catch {
    return false
  }
}
```

```ts
'use client'
import { useEffect, useRef, useState } from 'react'

// transitions.dev "Text states swap" as a hook: old text exits up with blur,
// React renders the new text, then it enters from below.
export function useTextSwap(value: string) {
  const ref = useRef<HTMLSpanElement>(null)
  const [shown, setShown] = useState(value)
  const phase = useRef<'idle' | 'entering'>('idle')

  useEffect(() => {
    const el = ref.current
    if (!el || value === shown) return
    const dur = parseFloat(getComputedStyle(document.documentElement).getPropertyValue('--text-swap-dur')) || 150
    el.classList.add('is-exit')
    const t = setTimeout(() => {
      el.classList.remove('is-exit')
      el.classList.add('is-enter-start')
      phase.current = 'entering'
      setShown(value)
    }, dur)
    return () => clearTimeout(t)
  }, [value, shown])

  // After React has committed the new text: reflow, then let it transition to rest.
  useEffect(() => {
    const el = ref.current
    if (!el || phase.current !== 'entering') return
    phase.current = 'idle'
    void el.offsetHeight
    el.classList.remove('is-enter-start')
  }, [shown])

  return [shown, ref] as const
}
```

`components/sliding-tabs.tsx` (transitions.dev 16):

```tsx
'use client'
import { useLayoutEffect, useRef, type KeyboardEvent, type MouseEvent } from 'react'

export type TabOption = { id: string; label: string }

// transitions.dev "Tabs sliding". The pill glides on a pointer click; arrow keys
// move it instantly (keyboard actions are never animated).
export function SlidingTabs({ label, options, value, onChange, idPrefix, size = 'md' }: {
  label: string; options: TabOption[]; value: string; onChange: (id: string) => void; idPrefix?: string; size?: 'sm' | 'md'
}) {
  const bar = useRef<HTMLDivElement>(null)
  const pill = useRef<HTMLSpanElement>(null)
  const animate = useRef(false)

  const place = (smooth: boolean) => {
    const tab = bar.current?.querySelector<HTMLButtonElement>('[aria-selected="true"]')
    const p = pill.current
    if (!tab || !p) return
    if (!smooth) p.style.transition = 'none'
    p.style.transform = `translateX(${tab.offsetLeft - 3}px)`
    p.style.width = `${tab.offsetWidth}px`
    if (!smooth) {
      void p.offsetWidth
      p.style.transition = ''
    }
  }
  useLayoutEffect(() => {
    place(animate.current)
    animate.current = false
  }, [value])
  useLayoutEffect(() => {
    const onResize = () => place(false)
    window.addEventListener('resize', onResize)
    return () => window.removeEventListener('resize', onResize)
  }, [])

  const pick = (id: string, e: MouseEvent | KeyboardEvent) => {
    animate.current = e.type === 'click' && (e as MouseEvent).detail > 0
    onChange(id)
  }
  const onKey = (e: KeyboardEvent) => {
    const i = options.findIndex((o) => o.id === value)
    const next = e.key === 'ArrowRight' ? (i + 1) % options.length : e.key === 'ArrowLeft' ? (i - 1 + options.length) % options.length : -1
    if (next < 0) return
    e.preventDefault()
    pick(options[next].id, e)
    bar.current?.querySelectorAll<HTMLButtonElement>('[role="tab"]')[next]?.focus()
  }

  return (
    <div ref={bar} className={`t-tabs max-w-full overflow-x-auto ${size === 'sm' ? 'text-xs' : 'text-sm'}`} role="tablist" aria-label={label} onKeyDown={onKey}>
      <span ref={pill} className="t-tabs-pill shadow-[var(--card-shadow)]" aria-hidden="true" />
      {options.map((o) => (
        <button
          key={o.id}
          type="button"
          role="tab"
          id={idPrefix ? `${idPrefix}-tab-${o.id}` : undefined}
          aria-controls={idPrefix ? `${idPrefix}-panel-${o.id}` : undefined}
          aria-selected={o.id === value}
          tabIndex={o.id === value ? 0 : -1}
          className="t-tab shrink-0 font-medium"
          onClick={(e) => pick(o.id, e)}
        >
          {o.label}
        </button>
      ))}
    </div>
  )
}
```

```js
// How the site reads page-as-data's own text output: which lines are problems,
// and when each line appears in a replay.
export function lineKind(line) {
  if (!line.trim()) return 'blank'
  if (/^\s*error {2,}/.test(line)) return 'error'
  if (/^\s*warning {2,}/.test(line)) return 'warning'
  if (/^\s+· /.test(line)) return 'detail'
  if (/^✖ /.test(line)) return 'fail'
  if (/^! /.test(line)) return 'warn-head'
  if (/^✔ /.test(line)) return 'pass'
  if (/^\d+ page checks? · /.test(line)) return 'summary'
  if (/^\s*• /.test(line)) return /\(warning\)|^\s*• console\.error/.test(line) ? 'warning' : 'error'
  if (/^[A-Z][A-Z /]+$/.test(line.trim()) || /^TABLE \d/.test(line)) return 'section'
  if (/ @ \d+px/.test(line)) return 'title'
  return 'text'
}

export function problemLines(output) {
  const lines = output.split('\n')
  const start = lines.indexOf('PROBLEMS')
  if (start < 0) return []
  const out = []
  for (const l of lines.slice(start + 1)) {
    if (!/^\s*• /.test(l)) break
    out.push(l.replace(/^\s*• /, ''))
  }
  return out
}

export function replaySchedule(lines, { reduced = false, step = 40, max = 1200 } = {}) {
  let t = 0
  return lines.map((text) => {
    const kind = lineKind(text)
    const at = reduced ? 0 : Math.min(t, max)
    if (kind !== 'blank') t += step
    return { text, kind, at }
  })
}
```

```tsx
'use client'
import { useEffect, useRef, useState } from 'react'
import { replaySchedule } from '@/lib/terminal.mjs'

const TONE: Record<string, string> = {
  error: 'text-danger', fail: 'text-danger font-medium', warning: 'text-warn', 'warn-head': 'text-warn font-medium',
  pass: 'text-ok', summary: 'text-text font-medium', detail: 'text-muted', section: 'text-muted', title: 'text-text', text: 'text-muted', blank: '',
}
const SETTLE_MS = 1100

// A replay of a real `check` run: the command, a shimmering "settling" line
// while it "runs", then the real output line by line. Starts once when scrolled
// into view; Replay runs it again. Reduced motion shows the finished output.
export function TerminalReplay({ command, output, name }: { command: string; output: string; name: string }) {
  const lines = output.split('\n')
  const box = useRef<HTMLDivElement>(null)
  const [phase, setPhase] = useState<'idle' | 'settling' | 'printing' | 'done'>('done')
  const [shown, setShown] = useState(lines.length)
  const timers = useRef<ReturnType<typeof setTimeout>[]>([])

  const play = () => {
    const reduced = matchMedia('(prefers-reduced-motion: reduce)').matches
    timers.current.forEach(clearTimeout)
    if (reduced) return setPhase('done'), setShown(lines.length)
    setShown(0)
    setPhase('settling')
    const plan = replaySchedule(lines)
    timers.current = [
      setTimeout(() => setPhase('printing'), SETTLE_MS),
      ...plan.map((l, i) => setTimeout(() => setShown(i + 1), SETTLE_MS + l.at)),
      setTimeout(() => setPhase('done'), SETTLE_MS + (plan.at(-1)?.at ?? 0) + 40),
    ]
  }

  useEffect(() => {
    const el = box.current
    if (!el || matchMedia('(prefers-reduced-motion: reduce)').matches) return
    setPhase('idle')
    setShown(0)
    const io = new IntersectionObserver(([e]) => {
      if (e.isIntersecting) {
        io.disconnect()
        play()
      }
    }, { rootMargin: '0px 0px -20% 0px' })
    io.observe(el)
    return () => { io.disconnect(); timers.current.forEach(clearTimeout) }
  }, [])

  return (
    <div ref={box} className="overflow-hidden rounded-2xl border border-border bg-code">
      <div className="flex items-center justify-between gap-3 border-b border-border px-4 py-2">
        <span className="font-mono text-xs text-muted">Terminal</span>
        <button type="button" onClick={play} className="press rounded-full bg-chip px-3 py-1 text-xs font-medium hover:bg-chip-hover" aria-label="Replay the check">Replay</button>
      </div>
      <pre tabIndex={0} data-check-output={name} className="max-h-[28rem] overflow-auto p-4 font-mono text-[12.5px] leading-6" aria-live="off">
        <span className="text-faint">$ </span><span className="text-text">{command}</span>{'\n'}
        {phase === 'settling' ? <span className="t-shimmer" data-text="Settling each page…">Settling each page…</span> : null}
        {lines.slice(0, shown).map((l, i) => (
          <span key={i} className={`block ${TONE[replaySchedule([l])[0].kind]} ${phase === 'printing' ? 'term-line' : ''}`}>{l || ' '}</span>
        ))}
      </pre>
    </div>
  )
}
```

```ts
'use client'
import { useCallback, useEffect, useRef } from 'react'

// Scenes render their final frame. Script arms them (animations wait at frame 0)
// and plays them once when they scroll into view. Reduced motion never arms, so
// it keeps the final frame. ?t=1.2 freezes every scene at 1.2 s for screenshots.
export function useScene<T extends HTMLElement>() {
  const ref = useRef<T>(null)

  const replay = useCallback(() => {
    const el = ref.current
    if (!el || matchMedia('(prefers-reduced-motion: reduce)').matches) return
    el.removeAttribute('data-armed')
    el.removeAttribute('data-play')
    void el.offsetWidth
    el.setAttribute('data-armed', '')
    el.setAttribute('data-play', '')
  }, [])

  useEffect(() => {
    const el = ref.current
    if (!el || matchMedia('(prefers-reduced-motion: reduce)').matches) return
    el.setAttribute('data-armed', '')
    const t = new URLSearchParams(location.search).get('t')
    if (t !== null) {
      el.setAttribute('data-play', '')
      for (const a of el.getAnimations({ subtree: true })) {
        a.pause()
        a.currentTime = Number(t) * 1000
      }
      return
    }
    const io = new IntersectionObserver(([e]) => {
      if (e.isIntersecting) {
        el.setAttribute('data-play', '')
        io.disconnect()
      }
    }, { rootMargin: '0px 0px -15% 0px' })
    io.observe(el)
    return () => io.disconnect()
  }, [])

  return { ref, replay }
}
```

```tsx
'use client'
import { useEffect, useRef } from 'react'

// transitions.dev "Number pop-in", played once when the number scrolls into view.
export function Count({ value }: { value: number }) {
  const ref = useRef<HTMLSpanElement>(null)
  const text = value.toLocaleString('en-US')
  useEffect(() => {
    const el = ref.current
    if (!el) return
    const io = new IntersectionObserver(([e]) => {
      if (!e.isIntersecting) return
      io.disconnect()
      el.classList.remove('is-animating')
      void el.offsetWidth
      el.classList.add('is-animating')
    })
    io.observe(el)
    return () => io.disconnect()
  }, [])
  const digits = [...text]
  return (
    <span ref={ref} className="t-digit-group tabular-nums" aria-label={text}>
      {digits.map((d, i) => (
        <span key={i} className="t-digit" aria-hidden="true" data-stagger={i >= digits.length - 2 ? String(i - digits.length + 3) : undefined}>{d}</span>
      ))}
    </span>
  )
}
```

```tsx
'use client'
import Link from 'next/link'
import { useEffect, useRef, useState } from 'react'

export function SkillsMenu({ skills }: { skills: { slug: string; title: string }[] }) {
  const [open, setOpen] = useState(false)
  const menu = useRef<HTMLDivElement>(null)
  const trigger = useRef<HTMLButtonElement>(null)

  useEffect(() => {
    const el = menu.current
    if (!el) return
    const closeMs = parseFloat(getComputedStyle(document.documentElement).getPropertyValue('--dropdown-close-dur')) || 150
    if (open) {
      el.classList.remove('is-closing')
      el.classList.add('is-open')
      return
    }
    if (!el.classList.contains('is-open')) return
    el.classList.remove('is-open')
    el.classList.add('is-closing')
    const t = setTimeout(() => el.classList.remove('is-closing'), closeMs)
    return () => clearTimeout(t)
  }, [open])

  useEffect(() => {
    if (!open) return
    const onKey = (e: KeyboardEvent) => { if (e.key === 'Escape') { setOpen(false); trigger.current?.focus() } }
    const onDown = (e: PointerEvent) => { if (!menu.current?.contains(e.target as Node) && e.target !== trigger.current) setOpen(false) }
    document.addEventListener('keydown', onKey)
    document.addEventListener('pointerdown', onDown)
    return () => { document.removeEventListener('keydown', onKey); document.removeEventListener('pointerdown', onDown) }
  }, [open])

  return (
    <div className="relative sm:hidden">
      <button ref={trigger} type="button" aria-expanded={open} aria-controls="skills-menu" onClick={() => setOpen((o) => !o)} className="press inline-flex min-h-6 items-center gap-1 text-muted hover:text-text">
        Skills
        <svg className="size-3.5" viewBox="0 0 16 16" fill="none" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" aria-hidden="true"><path d="m4 6 4 4 4-4" /></svg>
      </button>
      <div ref={menu} id="skills-menu" className="t-dropdown card absolute left-0 top-full z-40 mt-2 w-52 p-1.5" data-origin="top-left">
        <ul>
          {skills.map((s) => (
            <li key={s.slug}>
              <Link href={`/${s.slug}`} onClick={() => setOpen(false)} className="block rounded-lg px-3 py-2 text-sm hover:bg-chip">{s.title}</Link>
            </li>
          ))}
        </ul>
      </div>
    </div>
  )
}
```

```js
const ALLOWED = /^(https?:|mailto:)/i
export function rewriteHref(href, { pkg, slug, known, anchors = new Map(), base = '' }) {
  if (isAbsolute(href)) return ALLOWED.test(href) ? href : null
  if (href.startsWith('#')) {
    const id = href.slice(1)
    if (known.has(id)) return `/${slug}/${id}`
    if (anchors.has(id)) return `/${slug}/${anchors.get(id)}#doc-${id}`
    return `#doc-${id}`
  }
  if (href.startsWith('/')) return `${REPO}/blob/main${href}`
  const [path, hash] = href.split('#')
  const inPkg = posix.normalize(posix.join(base, clean(path)))
  return `${REPO}/blob/main/packages/${pkg}/${inPkg}${hash ? `#${hash}` : ''}`
}
```
